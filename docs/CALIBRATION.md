# 首次校准

校准只在使用者自己的机器本地完成。没有自动录制向导；发布过程也没有重新抓屏或发送测试消息。

## 输入与显示条件

先人工确认微信登录身份，给目标聊天设置不会与其他聊天混淆的三位 ASCII 数字备注。保证只存在一个符合原窗口标题与 Qt 类名的微信主窗口。公开实现保留已观察到的 Qt 类名，UI 更新可能使它直接停止；不要把修改类名理解为完成适配。

搜索区域按物理像素、以当前微信主窗口外框左上角为原点记录 `[left, top, right, bottom]`，不乘除逻辑缩放比。需要填写：

| 字段 | 含义 |
| --- | --- |
| `dpi` | 当前目标窗口的实际 DPI；运行时仍要求一致 |
| `search_strip` | 包含完整搜索框轮廓、放大镜及标签的窄条 |
| `field_anchor` | 初始搜索框矩形，用于既有弹窗的区域关联；点击仍取实时图像识别到的框 |
| `title_strip` | 打开聊天后的顶部标题区域；右边界由当前窗口宽度计算，保留原逻辑 |
| `results_pane` | 原配置字段，作为历史布局描述保留；实际结果捕获使用实时 Qt 弹窗边界 |

`config.example.json` 的布局为空，不含维护者电脑的实测参数。填写配置不代表新的缩放/主题已兼容：原搜索框和头像算法仍有原来的像素条件，改变显示条件需要单独实机验证。主窗口太大、覆盖全部可用工作区时，持续提示条没有安全位置会停止。

## 任务栏图标

从自己人工查看的本地任务栏截图裁出图标，保持 1:1 物理像素，不缩放；裁图宽高均须在 16..96 像素。只保留本机本地文件。以已知当前 DPI 替换下面占位参数：

```powershell
python tools/bind_taskbar_template.py --icon .local/my-icon.png --dpi <当前DPI> --output .local/calibration/taskbar-binding.json --confirmed
```

工具不截屏、不点击，只复制已审阅图标到本地并写入 SHA-256 绑定。已存在的输出不会被覆盖。原定位算法要求图标相关分数至少 0.97，第二个相似结果低于 0.90；透明、过小、裁剪不完整或重复图标可能无法通过。只支持主屏底部可见任务栏，不会自动展开分组预览。

## OCR 资源

安装固定版本的 `[desktop]` 可选依赖后运行 `tools/configure_ocr.py`。它按已安装 `rapidocr-onnxruntime==1.4.4` 的模型文件名和哈希生成 `cpu-only-config.yaml`。保留 Det/Cls/Rec 的 CPU 设置，拒绝 CUDA/DML。运行时 OCR 还会禁用网络连接；不会边发消息边下载或安装。

模板中的识别、检测及分类参数保留原值。原初始化设置 `det_limit_type="max"`、`det_limit_side_len=1024`、2 个 intra-op / 1 个 inter-op 线程，并在合成文字上预热。不要将配置工具产生的机器绝对模型路径提交到 Git。

## 启用

确认本地文件、路径和人工目标绑定后，在本地配置设置 `calibrated: true`。先运行不带 `--live` 的命令，检查消息数量和幂等结果。实发需自己选择授权测试聊天，以 `--live` 显式开始；代码仓的单测不会完成这一步。示例只用于 dry-run，不能宣称其坐标或目标可直接使用。
